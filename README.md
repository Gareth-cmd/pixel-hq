# Pixel HQ — temporary construction site

An intentionally small, dependency-free static landing page for Pixel Creative Studio.

## Local preview

Run `python3 -m http.server 8000` in this directory, then open `http://localhost:8000`.

## GitHub Pages

Publish from the repository root on the `main` branch. The included `.nojekyll` file ensures the static files are served directly.

The custom domain is deliberately not configured yet. Do not add a `CNAME` file until the GitHub Pages preview has been approved.
